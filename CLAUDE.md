# PayPal AI Hackathon

Entry for https://paypalaihackathon.devpost.com/. Build something that uses the PayPal sandbox and AI.

- Deadline: Nov 12, 2026, 12:00 PST (21:00 Germany). Aim to submit by Nov 10.
- Project: **Clubkeep**, an AI treasurer for clubs (matches PayPal payments to members, refunds, invoices).
- Stack: Node 22 + Express, plain JS frontend with AG Grid Community, transformers.js MiniLM on the server,
  PayPal REST (Transaction Search, Invoicing v2, Payments v2 refunds, webhooks). `npm test`, `npm start`.
- What is left before submitting: `docs/SUBMIT.md`.
- Research, judging rules, prizes and the idea shortlist: `NOTES.md`. Read it before doing anything else.
- Current state and next steps: `Progress.md`.
